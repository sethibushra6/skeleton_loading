# skeleton_loading
# Skeleton Loading Demo

## Objective
This project demonstrates skeleton loading placeholders with a shimmer animation while data is loading asynchronously.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Features
- Skeleton shimmer animation
- Simulated asynchronous loading using setTimeout()
- Dynamic service cards
- Responsive layout

## How to Run
1. Open index.html in a browser.
2. Observe the skeleton placeholders.
3. Wait 3 seconds for the content to load.
